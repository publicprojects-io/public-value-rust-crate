# Roadmap

## Current release line

- Keep the 80-item API stable and maintain complete source coverage.
- Track upstream source corrections and changes to published thresholds.
- Improve examples and citations without inventing new formula surfaces.

## Longer term

- Add independently researched extensions only when an existing source topic explicitly exposes a
  missing connection and a published worked example can test it.
- Review the MSRV and dependency floor during major release planning.

## Not planned

- A web frontend, locale/translation system, database, or file-I/O layer.
- Numeric wrappers or bespoke APIs not required by a source topic.
- Logging, caching, builders, or serialization added solely for symmetry.
- Claims about adopters, funding, or community governance without real participants.

This roadmap is intentionally principle-based rather than promising dates the maintainers cannot
guarantee.
