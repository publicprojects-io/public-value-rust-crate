# References

The canonical topic-by-topic definitions and worked examples are in
[`public-value-metrics`](https://github.com/public-value-metrics/public-value-metrics), locale
`en-gb-oxendict`. Each public item's rustdoc names the topic it ports.

The independently researched extensions listed in `spec/topics.md` draw on these source families:

- HM Treasury, *The Green Book* and supplementary appraisal guidance.
- UK Department for Business, Innovation and Skills, *Additionality Guide*, fourth edition (2014).
- NICE technology appraisal guidance on cost per QALY.
- UNDP Human Development Reports technical notes for HDI and IHDI.
- WHO Global Burden of Disease methodology for DALYs.
- Gini (1936) and Atkinson (1970) inequality measures.
- Viscusi's compensating-wage-differential research for the value of a statistical life.
- Reichheld (2003) for Net Promoter Score.

Links and concise methodological context live beside each implementation so citations cannot drift
away from the code they support.
